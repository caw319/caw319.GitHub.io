# Claire Weisgarber — Portfolio A responsive personal portfolio site designed for GitHub Pages. ## Files - `index.html` — portfolio page - `style.css` — responsive styling - `assets/claire-headshot.jpg` — supplied headshot - `assets/Claire-Weisgarber-Resume-2026.pdf` — supplied resume ## Publish with GitHub Pages 1. Create a new GitHub repository (for example, `claire-weisgarber.github.io`). 2. Upload everything in this folder, keeping the `assets` folder intact. 3. In GitHub, open **Settings → Pages**. 4. Under **Build and deployment**, choose **Deploy from a branch**, then select your main branch and `/ (root)`. 5. Save. GitHub will provide the live site URL.
